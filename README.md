# Texas HS Game Finder — Custom Weight Sliders

This version restores user-controlled Game Score weights.

Defaults:
- Team Quality: 40%
- Recruit Talent: 35%
- Matchup Quality: 15%
- Importance: 10%

Users can change all four sliders at any time. The visible games are immediately
re-scored and re-sorted.

If the slider values do not add to 100, the site automatically normalizes them
so Game Score remains on a 0–100 scale.

A Reset button restores 40 / 35 / 15 / 10.

All existing strict-radius and statewide schedule behavior remains in place.
