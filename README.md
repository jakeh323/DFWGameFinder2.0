# Texas HS Game Finder — Expanded Players to Watch

This version contains 151 Texas prospects.

Coverage now includes:
- Ranked 2027 recruits
- Unranked/NR FBS and FCS college commits
- 2028 four-star watchlist prospects
- Selected rising underclassmen on talent-rich rosters

The point is to make Players to Watch useful even in games that do not feature
national top-100 recruits.

Recruit Talent:
When matched players exist, the site's 35% Recruit Talent component uses the
actual prospect list rather than only the old program-level estimate.

Important:
`prospectScore` and the star display are internal Texas HS Game Finder tiers used
to rank player importance. They should not be interpreted as an exact 247/On3/Rivals
composite rating unless a source specifically provides one.

Primary public sources:
- Dave Campbell's Texas Football in-state college commitment pages
- Dave Campbell's 2028 five-star watchlist
- Dave Campbell's talent-rich roster / rising prospect coverage
