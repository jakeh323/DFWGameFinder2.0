# Texas HS Game Finder — Top 100 by Area

This version is designed around ONE statewide master schedule for each week.

For any selected location:
1. Filter the statewide weekly pool by the selected radius.
2. Apply the fixed Game Score:
   - 40% Team Quality
   - 35% Recruit Talent
   - 15% Matchup Quality
   - 10% Importance
3. Sort the qualifying games.
4. Display up to the Top 100 for that location/week.

Preset locations:
Dallas, Fort Worth, Austin, Houston, San Antonio, Waco, Tyler, Lubbock,
Amarillo, Abilene, Midland/Odessa, College Station, Corpus Christi, El Paso.

Important:
The interface now supports Top 100 per area/week, but the size of the results still
depends on how many real games exist in season.json. To actually return close to
100 games in every major area every week, season.json needs a much larger statewide
schedule pool containing hundreds of games per week.
