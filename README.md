# DFW Game Finder — Free Version

No OpenAI API.
No GitHub Actions.
No Netlify Functions.
No secrets.

Upload these files to the root of a GitHub repo connected to Netlify:
- index.html
- season.json
- netlify.toml
- README.md

The website automatically selects the correct 2026 week from the visitor's date and allows browsing Weeks 1-10.
